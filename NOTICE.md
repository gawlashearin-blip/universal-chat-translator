# Attribution and modifications

Universal Chat Translator is an unofficial derivative of **Mini Chat Translator** by Real_SShwer:

https://github.com/ZHENXUWEI/mini-chat-translator-fabric

The implementation started from commit `d94f7a03eff323301bd16864052312b6fa143c18` on the upstream `fabric-1.21.11-cloth` branch. The upstream repository and its JAR metadata identify the original code as CC0 1.0, while its Modrinth listing identifies the project as CC BY 4.0. This derivative conservatively preserves attribution and uses CC BY 4.0 for its own distribution.

Major modifications include a new project identity; removal of Python, Baidu, and Google Cloud engines; an OpenAI-compatible translation engine; configurable endpoint, model, prompt, timeout, and temperature; safer error handling; connection testing; separate player/system classification; ordered concurrent translation; self-message suppression; configurable colors; in-game shortcuts; bilingual documentation; and automated tests.

This project is not affiliated with or endorsed by Real_SShwer.
